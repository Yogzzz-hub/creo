## 1. How to Use This Document
This implementation plan defines the exact sequence for building Creo. Each phase has a clear goal, a numbered task list, and explicit done criteria. The AI coding agent must complete each phase fully before moving to the next — never skip ahead or build features out of order.

* Phases 1–3 are pure setup and infrastructure — no product features yet
* Phases 4–9 build product features in dependency order (auth before portal, portal before tasks)
* Phase 10 is hardening, testing, and deployment — never skipped
* Each task is assigned to Frontend (FE), Backend (BE), or Both
* 'Depends On' column lists the task numbers that must be complete before starting

Instruct the AI coding agent at the start of each phase: 'We are now working on Phase [N] of the Creo Implementation Plan. Complete all tasks in this phase before we move on. Here are the 6 project documents for context: [paste documents]'
